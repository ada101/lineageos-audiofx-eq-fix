msm8998-common: audio: Make the equalizer a software-only effect

With the equalizer registered as an effect proxy, AudioFX's equalizer
has no audible effect on offloaded playback (for example Twelve playing
an MP3). Bass boost, virtualizer and reverb still work.

Register the software equalizer directly instead. It is not offloadable,
so the track is played through the mixer while the equalizer is enabled
and the equalizer works. Offload is used again once AudioFX is off.

Playback goes through the CPU instead of the DSP while the equalizer is
on, which should cost some battery.

Test: Play an MP3 in Twelve, enable AudioFX with an exaggerated
      equalizer setting. Equalizer is audible and the output thread is
      MIXER, instead of OFFLOAD with no effect.
